# קלות הגדרה ותפעול + שכבת AI

מקורות: impeccable `onboard`/`harden`, Vercel guidelines, STANDARDS §16 (Settings/Update UX), §18.3-18.4, Anthropic `claude-api` skill, home-hub `ai-intent-owner` (SmartAddBar pattern).

## ממד 8 — "קל להגדרה, קל לתפעול"

### C-1. Defaults חכמים — high
המוצר עובד **מיד** בלי לגעת בהגדרות: שפה מה-OS/דפדפן (`navigator.languages`, לא IP), theme מ-`prefers-color-scheme`, אזור זמן/מטבע מה-locale, מיקום ברירת מחדל סביר. כל הגדרה שחובה למלא לפני ערך ראשון = ממצא.

### C-2. מסך הגדרות — medium (§16)
- מקובץ לפי נושא (כללי / מראה / התראות / חשבון / מתקדם), לא רשימה שטוחה של 40 toggles. קובץ settings > 800 שורות (home-hub: 2,080) = לפרק לטאבים/sections.
- חיפוש בהגדרות אם > 15 פריטים.
- כל הגדרה: label + הסבר של שורה + הערך הנוכחי גלוי; שינוי נשמר **מיד** עם "נשמר ✓" (או כפתור שמור אחד לכל section) — לא "דורש הפעלה מחדש".
- "שחזר ברירת מחדל" לכל section; ייצוא/ייבוא הגדרות (JSON) לכלים.
- פעולות מסוכנות (מחק חשבון, אפס נתונים) בתחתית, באדום, עם confirm + הקלדת אישור.

### C-3. חיבורים ואינטגרציות — medium
כל integration (Google Calendar, WhatsApp, API key): מצב מחובר/לא ברור, כפתור "בדוק חיבור", תאריך סנכרון אחרון, שגיאה קריאה ("הטוקן פג — התחבר מחדש"), ניתוק בלחיצה. API keys לא מוצגים מלא אחרי שמירה.

### C-4. התקנה/עדכון (desktop, Chrome ext) — medium (§7/§16)
installer בשתי שפות, מיקום ברירת מחדל נכון, לא דורס נתוני משתמש; עדכון: בדיקה ברקע, הודעה לא חוסמת, "מה חדש" קצר, rollback אפשרי. Chrome ext: הרשאות מינימליות, options page מוסברת.

### C-5. תיעוד בתוך המוצר — low
`?` ליד הגדרות מורכבות (inline help), עמוד עזרה/FAQ מקושר מאותו מקום בכל המסכים (3.2.6), README/דף נחיתה עם "5 דקות ראשונות".

### C-6. תפעול יומיומי — medium
- הפעולה השכיחה ביותר ב-1 קליק/מקש (command bar `Ctrl+K`, FAB, quick-add).
- קיצורי מקלדת לדסקטופ (מתועדים ב-`?`), מודעים ל-layout לא-QWERTY.
- Undo לכל פעולה שכיחה; היסטוריה/גרסאות למה שחשוב.
- הכל זוכר מצב (פילטר, טאב, גודל חלון, עמודות).

## ממד 9 — שכבת AI: איפה זה מוסיף ערך אמיתי

### AI-1. עיקרון: AI מוריד חיכוך, לא מוסיף פיצ'ר — high
לשאול לכל מודול: "איפה המשתמש מקליד/מסווג/מחפש/מסכם ידנית?" — שם AI. לא "צ'אט עם הבוט" כללי בפינה.
דפוסים שמוכיחים ערך:
| דפוס | דוגמה | מדד |
|---|---|---|
| **Smart add** (שורה חופשית → ישות מובנית) | "חלב מחר 8 בבוקר" → משימה עם תאריך | % הוספות דרך smart-add, זמן להוספה |
| **סיווג/תיוג אוטומטי** | הוצאה → קטגוריה; מסמך → תיקייה | % תיקונים ידניים (< 10%) |
| **סיכום** | שיחת משפחה של 80 הודעות → 3 שורות | שימוש חוזר |
| **המלצה בהקשר** | "יש לך 3 משימות באותה שעה — להזיז?" | acceptance rate |
| **חיפוש סמנטי** | "המסמך של הביטוח" | success rate |
| **Vision** | צילום קבלה/צמח → נתונים | דיוק |
| **Proactive digest** | בוקר: "היום: 2 משימות, מזג אוויר, מה חסר במקרר" | פתיחות |

### AI-2. UX של פיצ'ר AI — high
- **input**: placeholder עם דוגמה ("נסה: 'תזכיר לי לשלם ארנונה ב-1 לחודש'"), אפשרות לדבר (mic) במובייל.
- **בזמן עבודה**: streaming או skeleton, ≤ 3s נתפס; אפשרות ביטול.
- **תוצאה**: תמיד **ניתנת לעריכה** לפני שמירה (AI מציע, המשתמש מאשר) — במיוחד לפעולות עם side effects; הסבר קצר "למה" כשרלוונטי.
- **כשלון**: fallback ידני ברור ("לא הבנתי — הוסף ידנית"), לא חסימה; offline = הפיצ'ר מוסתר/מושבת עם הסבר, לא שגיאה.
- **אמון**: לא להמציא נתונים; לסמן תוכן שנוצר ע"י AI; מדיניות פרטיות — מה נשלח למודל.
- **עלות**: cache לתשובות זהות, מודל קטן לסיווג (Haiku), גדול רק לסיכום/reasoning; budget יומי; לא לקרוא למודל על כל keystroke (debounce/submit).

### AI-3. הנדסה — medium (ראה skill `claude-api` לפרטים עדכניים)
- ברירת מחדל: `claude-sonnet-5` ל-UI, `claude-haiku-4-5-20251001` לסיווג/intent, `claude-opus-5-5`/`claude-fable-5-1` לסיכום מורכב.
- Tool use / structured output (JSON schema) ל-smart-add, לא regex על טקסט חופשי.
- system prompt עם הקשר המשתמש (שמות בני משפחה, מודולים, אזור זמן) — ו-eval set בעברית (home-hub: `intent-eval` skill) שרץ בכל שינוי prompt.
- מפתחות רק בצד שרת (route handler / edge function), rate limit לכל משתמש, לוג של קריאות (tokens, latency, שגיאות).
- prompt caching לפרומפט המערכת; streaming ל-> 2s.

### AI-4. מה לא לעשות — medium
- "AI" כ-badge שיווקי על פיצ'ר דטרמיניסטי.
- צ'אט פתוח בלי משימה מוגדרת (משתמשים לא יודעים מה לשאול) — עדיף 3–5 "prompts מוצעים" בהקשר.
- לחסום את הזרימה הרגילה עד שה-AI עונה.
- לשלוח PII למודל בלי צורך.

### ציון ממד 9
1–3: אין AI או צ'אט גנרי · 4–6: פיצ'ר AI אחד עובד אבל בלי fallback/עריכה · 7–8: 2–3 דפוסים מהטבלה, ניתנים לעריכה, eval קיים · 9–10: AI שקוף ומוטמע בכל מודול, מדדי שימוש, עלות מנוהלת.
